## 4. Methodology

The project will follow these main stages:

### 4.1 Data Acquisition
Collecting and organizing the original dataset from selected sources.

### 4.2 Data Cleaning and Preprocessing
Handling missing values, inconsistent formats, duplicate records, and other data quality issues.

### 4.3 Feature Engineering
Constructing meaningful variables and metrics from the collected data.

### 4.4 Exploratory Data Analysis (EDA)
Investigating distributions, trends, relationships, and potential anomalies using descriptive statistics and visualizations.

### 4.5 Statistical Analysis
Formulating hypotheses and applying appropriate statistical methods to evaluate relationships and differences.

### 4.6 Results and Interpretation
Presenting key findings, evaluating their significance, discussing limitations, and identifying potential directions for further investigation.
